# Обязательный состав ОПОП на каждый год набора

**Источник требований:** методический перечень (скриншот) — `docs/opop/source/opop-sostav-dokumentov.jpg`.

**Принцип:** комплект **ОПОП** формируется **отдельно на каждый год приёма** (год набора) по специальности. При внесении изменений в программу (приказ, согласование) в комплекте должны однозначно читаться **актуальные** и, где требуется, **предыдущие** версии документов — в первую очередь **учебных планов** и **рабочих программ**, затронутых правками.

---

## Перечень документов (как в нормативном списке)

| № | Документ | Назначение / примечание для кафедры ИС |
|---|----------|----------------------------------------|
| 1 | **ППССЗ** | Программа подготовки специалистов среднего звена по специальности (09.02.07, 09.02.11 и др.). |
| 2 | **Учебный план** | **На 1 курс**, **на 2 курс**, **на 3 курс** — отдельные файлы в составе ОПОП года набора. **Если вносились изменения** — в комплекте (или в согласованной папке года набора) хранятся **две редакции** учебного плана по затронутому курсу: **до правок** и **после изменений** (см. [IZMENENIYA_OPOP_PRIKAZ.md](./IZMENENIYA_OPOP_PRIKAZ.md), §3). |
| 3 | **Рабочая программа воспитания** | Входит в ОПОП; при смене только профильных дисциплин/практик обычно без правок, если не затронут КУГ/воспитательные блоки. |
| 4 | **Справка МТО** | Материально-техническое обеспечение; при смене формы ГИА (ДЭ) и практик — проверить соответствие пунктов практикам и аттестации. |
| 5 | **Кадровая справка** | Кадровое обеспечение реализации программы. |
| 6 | **Рабочие программы** | Полный набор РП дисциплин, МДК, профессиональных модулей, практик. **Если в РП вносились изменения** из‑за приказа об ОПОП — фиксировать **редакцию** (дата, лист изменений); для практики ПДП→ППС и блока ВКР/ГИА — обязательна новая редакция. |
| 7 | **Программа ГИА** | В т.ч. при переходе на **демонстрационный экзамен** (см. изменения по 09.02.07, 8 сем.) — актуализировать программу ГИА и согласовать с ФОС. |
| 8 | **Фонд оценочных средств** | Перечень вопросов к экзаменам и **диф. зачёту**; при изменении компонентов аттестации — дополнить/пересмотреть ФОС. |
| 9 | **Лист согласования ОПОП (приложение 1)** | Итоговое согласование комплекта на год набора. |

## Как должно быть (организация комплекта)

Ниже — **практическая раскладка** для года набора, согласованная с перечнем выше и с правилом двух учебных планов при изменениях.

```text
ОПОП / <специальность> / год_набора_<YYYY>/
├── 01_PPSSZ.pdf
├── 02_uchebnye_plany/
│   ├── kurs_1/
│   │   └── UP_kurs_1.pdf
│   ├── kurs_2/
│   │   ├── UP_kurs_2_do_izmeneniy.pdf      # при наличии приказа
│   │   └── UP_kurs_2_posle_izmeneniy.pdf
│   └── kurs_3/
│       ├── UP_kurs_3_do_izmeneniy.pdf
│       └── UP_kurs_3_posle_izmeneniy.pdf
├── 03_RP_vospitanie.pdf
├── 04_spravka_MTO.pdf
├── 05_kadrovaya_spravka.pdf
├── 06_rabochie_programmy/
│   ├── ... дисциплины, МДК, ПМ ...
│   ├── praktiki/
│   │   ├── PDP_prediplomnaya/   # архивная редакция, если заменена
│   │   └── PPS_po_profilu/      # актуальная после приказа
│   └── GIА_VKR/                 # архив + актуальная при смене на ДЭ
├── 07_programma_GIA.pdf
├── 08_FOS/
│   ├── ekzameny/
│   └── dif_zachet/
└── 09_list_soglasovaniya_OPOP_pril_1.pdf
```

**Связь с приказом о внесении изменений:**

| Изменение в ОПОП (пример) | Документы из перечня, которые обновить |
|---------------------------|----------------------------------------|
| ПДП → ППС, тот же объём часов | п. **2** (УП), п. **6** (РП практики), при необходимости п. **4** (МТО) |
| Подготовка + защита ВКР → ГИА ДЭ 216 ч | п. **2**, **6**, **7**, **8** |
| Любая правка УП на 2/3 курсе | п. **2** — **две версии** на соответствующий курс; п. **6**–**8** по затронутым компонентам |

Журнал фиксации версий учебных планов: [zhurnal-uchebnyh-planov.md](./zhurnal-uchebnyh-planov.md).
