## 2. Какие документы затрагиваются

Изменения вносятся в **ОПОП** (основная профессиональная образовательная программа). Для исполнения на кафедре необходимо синхронизировать связанные локальные документы:

| Документ | Действие при изменении строки учебного плана |
|----------|-----------------------------------------------|
| **Учебный план** группы (по году приёма и специальности) | Две версии: **до** и **после** вступления изменений в силу (см. §3). |
| **Рабочая программа (РП)** практики | ПДП → ППС: обновить наименование, цели, содержание, оценочные средства; зафиксировать редакцию и дату. |
| **РП** по подготовке/защите ВКР | Для **09.02.07 (приём 2025), 8 сем.**: заменить или объединить логику под **ГИА — демонстрационный экзамен (216 ч)**. |
| **РП/программа ГИА / ДЭ** | Уточнить соответствие ФГОС СПО и регламенту демонстрационного экзамена по профессии. |
| **Календарный учебный график (КУГ)** | При смене наименований компонентов — актуализировать подписи периодов (если привязаны к ПДП/ВКР/ГИА). |
| **МТО, фонд оценочных средств** | При смене формы аттестации (акцент на ДЭ) — проверить комплектность. |

## 3. Два учебных плана на каждую группу (обязательная схема учёта)

**Правило:** для каждой **учебной группы**, по которой изменения ОПОП **реально применяются** (семестр из приказа совпадает с текущей или будущей траекторией группы), ведутся **две версии** учебного плана:

| Версия | Когда используется | Имя файла (рекомендация) |
|--------|--------------------|----------------------------|
| **До изменений** | Группы, освоившие или осваивающие семестр по **исходной** редакции ОПОП на момент начала семестра / до даты приказа | `УП_<группа>_до-изменений_<год-приёма>_v1.pdf` |
| **После изменений** | Группы, на которых действует **изменённая** редакция ОПОП с даты, указанной в приказе | `УП_<группа>_после-изменений_<год-приёма>_v2.pdf` |

**Минимальный паспорт версии** (журнал в `docs/opop/zhurnal-uchebnyh-planov.md`):

- специальность, год приёма, шифр группы;
- семестр, к которому относятся строки из приказа;
- дата и номер приказа;
- ссылка на файл учебного плана;
- перечень обновлённых РП (с номерами редакций).

## 5. Чеклист кафедры ИС после утверждения приказа

1. Получить **полный текст приказа** и дату вступления в силу.
2. Для каждой затронутой специальности/года приёма выгрузить **исходный** и **изменённый** фрагменты учебного плана (8 сем. — 09.02.07/2025; 6 сем. — 09.02.11/2026).
3. Разнести группы по колонкам «до» / «после» согласно §3.
4. Оформить **новые редакции РП** (ППС; ГИА/ДЭ для 09.02.07) с листом регистрации изменений.
5. Обновить **журнал учебных планов** и хранить обе PDF-версии в единой папке (см. `docs/opop/README.md`).
6. Дополнить §1.3 данными по **приёму 2023**, когда таблица будет доступна.
