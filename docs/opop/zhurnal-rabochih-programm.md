# Журнал редакций рабочих программ (после изменений ОПОП)

Вести для **п. 6** состава ОПОП: каждая **РП**, в которую внесены изменения по приказу или по новой редакции учебного плана, получает запись.

| Дата редакции | Спец. | Год набора | Дисциплина / модуль / практика | Было (кратко) | Стало (кратко) | № приказа / основание | Путь к файлу РП | Связанный УП (до/после) |
|---------------|-------|------------|--------------------------------|---------------|----------------|------------------------|-----------------|-------------------------|
| | 09.02.07 | 2025 | ПДП → ППС | ПДП преддипломная | ППС по профилю | | | |
| | 09.02.07 | 2025 | Подготовка/защита ВКР → ГИА ДЭ | 144 + 72 ч | ГИА ДЭ 216 ч | | | |
| | 09.02.11 | 2026 | ПДП → ППС | ПДП преддипломная | ППС по профилю | | | |

**Правило:** пока для строки приказа нет актуальной РП и отмеченного УП «после изменений», комплект ОПОП на год набора считается **неполным**.
